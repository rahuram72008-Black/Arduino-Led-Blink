# Arduino LED Blink

A simple Arduino LED blinking project created and tested using the Wokwi simulator.

## Components
- Arduino UNO
- LED
- 220Ω Resistor

## Programming
- Embedded C / Arduino C++

## Working
The LED turns ON for 1 second and OFF for 1 second continuously.

## Simulator
Wokwi
